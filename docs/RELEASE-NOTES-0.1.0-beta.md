# War Thunder Triple Screen v0.1.0-beta

Initial public beta for mixed-resolution triple-monitor layouts without NVIDIA
Surround.

Verified local result:

- centre: native 2560×1440 at 165 Hz;
- sides: physical 1920×1080 at effective 2560×1440 through NVIDIA DSR/DLDSR;
- final War Thunder outer and client rectangle: `x=-2560`, `y=0`,
  `7680×1440`;
- Windows display scale: 100% on every target monitor.

The release contains the one-click full launcher and the attach-to-running-game
window fix. Read `README.md` and `SECURITY.md` before use.

SHA-256 checksums are provided as a separate release asset.
